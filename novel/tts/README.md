# «Шатун» — чтецкая версия для ElevenLabs (Eleven v4)

Эта версия предназначена только для озвучки. Основной текст лежит в `novel/Шатун.md` и `novel/chapters/`. Чтецкая версия собирается из него скриптом:

```
cd novel && python3 tts/make_tts.py
```

## Файлы

| Файл | Что это |
|---|---|
| `full.txt` | Весь роман одним файлом (~585 тыс. символов). Для импорта в Studio / Projects. |
| `chapters/NN.txt` | По главе на файл. |
| `parts/NN-K.txt` | Главы, нарезанные на куски до 9 000 символов по границам абзацев. Это запас под лимит Eleven v4: 10 000 символов на запрос. Всего 79 кусков. |
| `stress_list.txt` | Все слова, в которые поставлен знак ударения, и число употреблений. |
| `pronunciation_ru.pls` | Словарь произношения (IPA, 47 правил) для имён и топонимов. Нужен только для версии без ударений (см. ниже). |
| `strip_accents.py` | Снимает знаки ударения, если модель на них спотыкается. |
| `make_tts.py` | Конвертер: все правила замен в одном месте. |

## Что известно про Eleven v4

Сведения собраны по документации ElevenLabs и обзорам; сам сайт из этой сессии напрямую открыть не удалось. Перед большой озвучкой проверьте на одной главе.

- **Модель:** `eleven_v4`, вышла 28.09.2026. Есть быстрый вариант `eleven_v4_turbo`, но для аудиокниги нужна обычная v4.
- **Лимит:** 10 000 символов на один запрос через API и Playground. Для длинного текста — Studio (Projects) или наши куски `parts/`.
- **Паузы:** SSML-теги `<break time="…"/>` в v4 **не работают**. Паузы задаются аудиотегами `[pause]`, `[long pause]`, многоточием и тире.
- **Аудиотеги:** свободный текст в квадратных скобках, ставится прямо перед фразой, которую меняет: `[whispers]`, `[sighs]`, `[crying]`, `[screaming]` и т. п. Фиксированного списка нет. Теги пишутся по-английски: так модель понимает их надёжнее.
- **КАПС** модель читает как **ударное выделение**, усиливает голос. Поэтому весь авторский КАПС (видения, вывески, газетные шапки) переведён в обычный регистр. Где нужен нажим, стоит тег.
- **Произношение:** v4 понимает IPA прямо в тексте между слэшами `/…/` и словари произношения с правилами `phoneme` (IPA) и `alias`. SSML `<phoneme>` не поддерживается.
- **Нормализация текста** (`apply_text_normalization`: `on` / `off` / `auto`) для русского не документирована. Поэтому **все числа, даты, проценты и суммы уже написаны словами**. Нормализацию можно выключить (`off`). Если параметр доступен, укажите `language_code: "ru"`.
- **Разметка Markdown** может прочитаться вслух. В этой версии нет ни `*`, ни `#`, ни `>`, ни таблиц, ни псевдографики: скрипт это проверяет.
- **Стабильность:** у v3 было три пресета (Creative / Natural / Robust); у v4, судя по обзорам, похоже. Для романа берите **Natural**: Creative может «фантазировать», Robust хуже слушается тегов. Регулятора скорости в v4 нет, темп задаётся тегами `[slowly]` / `[rushed]` и пунктуацией.
- **Совет из документации:** теги — это подсказка, а не команда. Важные места генерируйте в 2–3 дублях и выбирайте лучший.

## Пометки в тексте

| Пометка | Где | Зачем |
|---|---|---|
| `[long pause]` | Перед частями, на месте разделителей сцен (147 раз) | Длинная пауза между сценами. |
| `[pause]` | После заголовка главы, после видений, вместо ремарки «(Пауза.)» (73 раза) | Короткая пауза. |
| `[softly, dreamlike] … [pause]` | Все видения Мити, бывшие в скобках (25) | Тихая, «нездешняя» подача, чтобы видение отличалось от повествования. |
| `[screaming]` | «Отдай Ваню, гад!» | Крик. |
| `[whispers]` | «Мама, я больше не буду» в видении | Шёпот. |
| `[crowd chanting]` | Скандирование «Не пу-сто-е ме-сто!» | Толпа. |
| `[crying]`, `[paper rustling]`, `[murmuring]` | Ремарки в стенограммах | Вместо чтения слов «Плачет», «Вскрывает конверт», «Шум в зале». |
| Знак ударения (´) | ~1570 мест, 244 разных словоформы | Топонимы, фамилии, омографы (см. ниже). |

### Ударения

Знак ударения — комбинируемый акут U+0301, стоит после ударной гласной: «в Шу́ю», «Ива́ново», «Бараба́ш».

- **Топонимы во всех падежах:** Шу́я/Шу́ю/Шу́е, Пря́жа, Кине́шма, Ко́хма, Шарья́, Тихоре́чье, Волжа́нск, Ива́ново / в Ива́нове / из Ива́нова, Нефтею́ганск, Нижнева́ртовск, Я́рцево, Судисла́вль, Коте́льнич, Мо́хово, Глини́щи, Мо́крое, Суху́ми, Рабфа́ковская, Шереме́тевский и др.
- **Фамилии и имена во всех формах:** Бараба́ш, Лу́рье, Стре́льников, Раки́тин, Брусни́цын, Ла́скин, Гля́нцев, Па́сько, Гу́сев, Ираи́да, Шу́мский, Коро́бов, Ца́пкин, Рыжо́в, Бессо́нов, Ланско́й/Ланско́го/Ланска́я, Кочетко́в, Стра́хов, Клочко́в, Мзи́я, Нгуе́н Ван Тха́нь, Ко́тя, На́йда, Ге́нка и др. Полный список — в `stress_list.txt`.
- **Омографы.** Где ударение однозначно, оно поставлено везде: замо́к, муко́й, «Ве́сти» и «без ве́сти», по́лки, атла́сное, вина́, звони́т/позвони́т/звоня́т. Где зависит от смысла, расставлено вручную по контексту: хло́пок (хлопок не пришёл) — хлопо́к (выстрел), сто́ит (цена) — стои́т (оставлено без знака), це́лую (банку, кучу) — целу́ю (в письме), соро́ка (птица), Ивано́ва (фамилия) — Ива́нова (город).
- **Буква «ё»** стоит в тексте последовательно (больше 3000 раз), это само по себе снимает много ошибок.

### Если ударения мешают

Комбинируемый акут в v4 официально не описан. Если на пробе модель на нём спотыкается (пауза, странный звук, проглоченная буква):

1. Сделайте версию без ударений: `python3 tts/strip_accents.py tts/full.txt > tts/full_noaccent.txt` (то же и для кусков).
2. Загрузите `pronunciation_ru.pls` как словарь произношения (Studio → Pronunciation dictionaries или через API). Там IPA-правила для 47 самых важных имён и топонимов во всех встречающихся формах. Словарь работает только на тексте **без** ударений: в нём ищутся слова в обычном написании.
3. Оставшиеся омографы правьте точечно прямо в тексте, через IPA между слэшами, например `/ˈʂuju/`.

## Что сделано с текстом

- **Разметка:** заголовки стали фразами («Глава двадцать первая. Шайба.»); курсив, жирный, цитаты и разделители убраны; разделители заменены на `[long pause]`.
- **Таблица дежурств (гл. 19)** пересказана словами. Рамка «Времени ещё много» (гл. 29) превращена в обычный абзац.
- **Числа** написаны словами в нужном падеже, около 220 мест: даты («двенадцатого октября тысяча девятьсот девяносто шестого года»), годы рождения, возрасты, проценты («пятьдесят одна целая три десятых процента»), суммы, номера школ, домов, вагонов, телефон («два — четырнадцать — тридцать семь»), код камеры хранения («Тэ — два — один — шесть»), гравировка на кольце, записи в тетрадях («Одиннадцатое июня»), надпись на камне.
- **Аббревиатуры** записаны так, как произносятся, строчными, чтобы модель не прочла их как выделение: о-вэ-дэ, эф-эс-бэ, у-вэ-дэ, эл-эф-ка, цэ-эр-бэ, дэ-эр-эс-у, эр-тэ-эр, ка-пэ-эр-эф, эм-эм-эм, гаи́, ови́р и т. д. Статьи УК, «РФ», «США» раскрыты словами.
- **Инициалы** раскрыты полностью: «Г. А. Стрельников» → «Григорий Аркадьевич Стрельников». Сокращения тоже: «г. р.» → «года рождения», «ул.» → «улица», «пос.» → «посёлок», «P. S.» → «Постскриптум», «NB» → «Нота бене».
- **Латиница** записана кириллицей так, как её произнёс бы русский рассказчик: «Мальборо», «Сникерс», «Лав из», «мейд ин чайна», «зе систем».

## Как озвучивать

1. Возьмите одну главу, лучше 25-ю: в ней есть видения, крик, толпа и ударения. Прогоните её целиком на выбранном голосе с настройкой **Natural**.
2. Послушайте: ударения в топонимах, видения (`[softly, dreamlike]`), паузы `[long pause]`. Если что-то не так, см. «Если ударения мешают» или поправьте правило в `make_tts.py` и пересоберите.
3. Дальше — Studio: импорт `full.txt` (или по главам из `chapters/`), либо API по кускам из `parts/` по порядку номеров. Для ровной подачи между кусками используйте склейку контекста (`previous_text` / `next_text`, если доступно).
4. Нарратор — один голос. Если захотите разные голоса для стенограмм (Коробов, Лурье, свидетели), в Studio их удобно назначить по абзацам: реплики там начинаются с имени и двоеточия.
