## Порядок работы во Flow

1. **Сначала создайте героев** по листам из `../character_sheets.md` и назовите их так: MITYA, MITYA_KID, LIZA, STRELNIKOV, SIVY, MUKHA, VADIM, NIKOLAI, GALINA, LURIE, BARABASH, GUSEV, RAKITIN, IRINA, KIRILL, VANYA_THANH, VIKA, LANSKOY, RYZHOV, LASKIN, VERA, UNCLE_TOLYA, BABY_VANYA, VANYA_SHUMSKY, STEPA, ANNA_STEPANOVNA, STRAKHOV.
2. **Возраст и одежда** героя меняются словами в промпте: в скобках у STRELNIKOV стоит возраст (23 / 42 / белые волосы), у MITYA — 26 / 28 / «в ватнике». Лицо и приметы Flow берёт из героя.
3. **Вторые роли** описаны прямо в тексте промпта (Жора, Тамара, Брусницын, Цапкин, Курбатов, Коробов, Маркелыч и др.). Если хотите единый облик, создайте их тоже.
4. **Один абзац = один кадр.** Стиль уже вписан в конец каждого промпта, ничего добавлять не нужно. Видения и документы получают дополнительную строку стиля.
5. **Если Flow отказывается** генерировать сцену (дети в опасности, пожар, самоубийство), замените её более мягким кадром: тот же свет, только дым, решётка, пустой стул, рука. В промптах эти сцены и так даны без жестокости, насилие показано только намёком.
6. **Монтаж.** Меняйте кадр по времени из заголовка главы: ≈ 3–4 минуты. Эффект Кена Бёрнса (медленный наезд) и мягкий щелчок проектора между кадрами делают неподвижные картинки живыми. В видениях добавьте серый «снег» и немного звука помех.
7. **Не забудьте:** кадры «документ» хорошо ложатся на анимацию скольжения камеры вдоль бумаги.
