# Листы персонажей «Шатуна» (стиль B)

В списке только те, кто появляется в кадре больше одного раза. Приметы взяты из текста книги, в скобках указаны главы. Промпты на английском. Формат листа — 3:2 или 16:9: так помещаются все ракурсы.

## Как пользоваться

1. **Основа листа** (ниже) копируется дословно вместо `[ОСНОВА ЛИСТА]` в начале каждого промпта. Дальше идёт описание персонажа.
2. **Сгенерируйте 3–4 варианта** и выберите один удачный. Он и станет «эталоном» героя.
3. **Подставляйте эталон** как референс персонажа в каждый кадр раскадровки:
   - Midjourney: `--cref <ссылка на лист> --cw 60` (100 — переносить ещё и одежду, 0 — только лицо);
   - Flux, Leonardo, Ideogram: Character reference / IP-Adapter / «образ персонажа»;
   - ChatGPT Images: прикрепите лист и напишите «this exact character».
4. **Возраст и одежду** меняйте словами, лицо и приметы — никогда.
5. Если генератор позволяет, **зафиксируйте seed** для листа, который понравился.

**Основа листа (стиль B):**
```
Character model sheet for an adult literary thriller, hand-drawn in gouache and dry brush on textured cream paper, visible pencil construction lines, realistic human proportions, small realistic eyes, no cartoon exaggeration, muted palette of grey-blue, ochre and faded brown, soft even studio light. Layout: full-body front view, full-body side profile, full-body three-quarter back view, plus two head close-ups with different expressions, all of the same person, evenly spaced on a plain light paper background. 1990s provincial Russia. No text, no labels.
```

**Негатив для всех листов:**
```
cartoon, anime, chibi, cute, big eyes, rosy cheeks, caricature, exaggerated nose, 3D render, photo, glossy, multiple different people, inconsistent face, text, letters, watermark, logo
```
