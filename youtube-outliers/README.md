# YouTube Outliers — поиск роликов с аномальными просмотрами

Скрипт ищет на YouTube ролики, которые **набрали в разы больше просмотров, чем обычно набирает их канал**
(«выбросы», outliers). Обычно это темы и упаковки (название и обложка), которые «выстрелили». Такие ролики имеет смысл разбирать
и повторять в своей нише.

## Как считается «аномальность»

Для каждого найденного ролика скрипт загружает последние ролики его канала **того же формата**
(Shorts сравниваются с Shorts, обычные ролики с обычными) и считает:

| Метрика | Что значит |
|---|---|
| **× к медиане** (`score`) | просмотры ролика ÷ медиана просмотров канала. `5×` значит, что ролик набрал в 5 раз больше обычного |
| **просм./подп.** | просмотры ÷ подписчики. Больше 1 значит, что ролик вышел за пределы аудитории канала |
| **просм./день** | скорость набора просмотров |
| **z-score** | насколько ролик выбивается из разброса канала (считается по логарифму просмотров, устойчив к выбросам). ≥3 значит сильный выброс |

Ролики моложе 3 дней в медиану не попадают (`--baseline-min-age`), иначе они занижают «норму» канала.

## Установка

```bash
cd youtube-outliers
pip install -r requirements.txt
```

Нужен Python 3.10+.

## Два источника данных

1. **Без ключа (yt-dlp)** работает сразу. Минусы: просмотры в списках канала округлены (722K),
   даты приблизительные («2 недели назад»), у Shorts дат нет, если не включить `--enrich`.
   Если YouTube начнёт писать «подтвердите, что вы не бот», добавьте `--cookies-from-browser chrome`.
2. **YouTube Data API v3** даёт точные цифры и даты, а также фильтры по стране и языку. Ключ бесплатный:
   [Google Cloud Console](https://console.cloud.google.com/apis/library/youtube.googleapis.com) →
   включить *YouTube Data API v3* → *Credentials* → *Create API key*. Затем:
   ```bash
   export YOUTUBE_API_KEY=ваш_ключ
   ```
   Квота 10 000 единиц в сутки. Один поиск (50 роликов) стоит 100 единиц, данные канала около 2–3 единиц.
   Примерно 30–50 запросов в день. Повторные запуски берут каналы из кэша (12 часов).

Если ключ задан, скрипт сам использует API (`--backend auto`).

## Примеры

Аномальные ролики по теме за месяц:
```bash
python yt_outliers.py -q "рецепты пп" --period month
```

Маленькие каналы, которые выстрелили (до 50K подписчиков, просмотров больше, чем подписчиков):
```bash
python yt_outliers.py -q "ремонт квартиры" --max-subs 50000 --min-views-per-sub 1 --min-score 5
```

Только Shorts, сортировка поиска по просмотрам:
```bash
python yt_outliers.py -q "лайфхаки" --type shorts --period week --search-sort views
```

Разобрать конкретные каналы (конкурентов): какие их ролики выбились из нормы:
```bash
python yt_outliers.py -c @channel1 -c https://www.youtube.com/@channel2 --min-score 2 --max-per-channel 10
```

Много запросов из файла и все критерии в JSON:
```bash
python yt_outliers.py --queries-file queries.example.txt --config criteria.example.json
```

Через API, только Россия, на русском, за последние 14 дней:
```bash
python yt_outliers.py -q "нейросети" --days 14 --region RU --lang ru
```

## Все критерии

| Опция | По умолчанию | Описание |
|---|---|---|
| `-q / --query`, `--queries-file` | | поисковые запросы |
| `-c / --channel`, `--channels-file` | | каналы: `@handle`, `UC…` или ссылка |
| `--limit` | 100 | сколько роликов брать из поиска на запрос |
| `--period` | | `hour` / `today` / `week` / `month` / `year` — фильтр поиска по дате |
| `--days` | | (API) загружено за N дней |
| `--search-sort` | relevance | `relevance` / `views` / `date` / `rating` |
| `--search-duration` | | `short` (<4 мин) / `medium` (4–20) / `long` (>20) |
| `--type` | all | `all` / `long` / `shorts` |
| `--min-score` | 3 | во сколько раз больше медианы канала |
| `--min-zscore` | | минимальный z-score |
| `--min-views` / `--max-views` | 1000 / — | границы просмотров |
| `--min-subs` / `--max-subs` | | границы подписчиков |
| `--min-views-per-sub` | | просмотров на подписчика |
| `--min-views-per-day` | | скорость набора |
| `--max-age-days` / `--min-age-days` | | возраст ролика (`--strict-dates` отбрасывает ролики без даты) |
| `--min-duration` / `--max-duration` | | длительность, сек |
| `--title-include` / `--title-exclude` | | слова в названии (можно несколько раз) |
| `--max-per-channel` | 3 | не больше N роликов с одного канала |
| `--baseline-videos` | 30 | сколько последних роликов канала брать для медианы |
| `--sort` | score | `score` / `views` / `vps` / `vpd` / `z` |
| `--top` | 50 | сколько результатов вывести |
| `--out` | results | папка для отчётов |

Полный список: `python yt_outliers.py --help`. В JSON-конфиге ключи те же, только через подчёркивание
(`min_score`, `max_subs`…).

## Результат

- таблица в консоли;
- `results/outliers_<дата>.html`: отчёт с обложками и сортировкой по клику на заголовок столбца;
- `.csv` (открывается в Excel, разделитель `;`) и `.json`.

## Ограничения

- Shorts определяются по вкладке канала, а если ролика там нет, то по длительности ≤ 3 мин.
- Без API у Shorts нет даты публикации, поэтому фильтры по возрасту к ним не применяются (`--enrich` уточняет дату, но часто требует cookies).
- yt-dlp парсит сайт YouTube. Если что-то сломалось, обновите его: `pip install -U yt-dlp`.
